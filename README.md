# 🛒 Blinkit Sales Analysis Dashboard

## 📌 Project Overview

This project is a **Power BI Dashboard** built using Blinkit grocery sales data. The dashboard provides interactive visualizations and business insights related to sales performance, outlet distribution, item categories, customer ratings, and outlet trends.

The goal of this project is to transform raw sales data into meaningful insights that help understand business performance and support data-driven decisions.

---

# 📊 Dashboard Features

* Total Sales Analysis
* Average Sales Tracking
* Number of Items Sold
* Customer Rating Analysis
* Outlet Establishment Trend
* Fat Content Distribution
* Item Type Performance
* Outlet Size Analysis
* Outlet Location Insights
* Outlet Type Comparison
* Interactive Filters & Slicers

---

# 🔍 Business Insights

* Tier 3 outlets generated the highest sales.
* Fruits and Snack Foods are top-performing item categories.
* Medium-sized outlets contribute the highest revenue.
* Supermarket Type 1 has the highest number of items sold.
* Sales peaked around outlet establishments in 2018.
